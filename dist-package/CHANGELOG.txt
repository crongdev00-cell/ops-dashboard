변경 이력 (개발심의회 대시보드 테스트 패키지)
=====================================

v0.03
-------------------------------------
- 포털 동기화 업로드 방식 변경: 파일을 base64로 감싸서 보내던 방식 → 파일 그대로 전송
  - 실제 사업포털처럼 큰 엑셀(수만 건)을 올릴 때 서버가 응답 없이 멈추거나 죽던 문제의
    원인이었음(base64로 감싸면 용량이 1.3배로 불어나고, 메모리에 파일 사본이 여러 개 동시에
    떠 있게 됨) — 6만 건(34MB) 파일로 직접 재현·확인 후 수정
  - 업로드 가능 용량도 10MB → 80MB로 늘림

v0.02
-------------------------------------
- 서버 연결 실패 안내 문구에 "(F5로 새로고침 해주세요)" 추가 — 에러가 떴을 때 뭘 해야 할지 바로 알 수 있음
- 진행 단계 안내 문구에서 내부 코드 용어("Y열") 제거하고 "심의방법"으로 수정

v0.01 (첫 배포)
-------------------------------------
- 표 보기: 행을 클릭하면 바로 상세 팝업이 뜨도록 변경 (예전처럼 셀 클릭 시 바로 수정되던 방식 제거)
- 헤더 버튼(안건 추가 / 포털 동기화 / 변경 이력 / 안건 검색) 클릭 시 색이 바뀌는 효과 추가 — 클릭이 됐는지 바로 알 수 있음
- AI 어시스턴트: 응답 대기 중 진행 표시(점 애니메이션 + 경과 시간) 추가
- 처음 열었을 때부터 예시 안건 20건이 채워진 상태로 시작 (미실시~결재완료 전 단계 포함)
  - data 폴더의 projects.json / history.json / comments.json 세 파일을 지우면 완전히 빈 상태로 리셋됨 (자동으로 다시 채워지지 않음)
- npm/Node 설치 없이 실행되는 포터블 패키지 구성 (run.bat + 동봉된 node.exe)
- 방화벽 경고가 뜨지 않도록 서버를 localhost 전용으로 바인딩
