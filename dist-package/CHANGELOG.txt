변경 이력 (개발심의회 대시보드 테스트 패키지)
=====================================

v0.26 (레거시 심의방법 "전자결재" 인식 완화)
-------------------------------------
- 실제 레거시 엑셀에 "전자결재"라고 적혀 있는데도 미지정으로 빠지던 문제 수정.
  다른 프로그램을 거친 옛 엑셀의 한글 자모 분리(NFD) 저장이나 "전자결재(전결)"
  같은 괄호 변형도 이제 전자결재(본부장)으로 정상 인식됨.

v0.25 (레거시 이관 — 국책사업 사업부문 기본값 + 전자결재(본부장) 추가)
-------------------------------------
- 레거시 업로드로 생성되는 국책사업의 사업부문이 미지정으로 고정돼 있던 걸
  일반 사업과 동일하게 "미래전장사업부문"으로 기본 지정.
- 옛 엑셀 심의방법 "전자결재"가 인식 안 돼 미지정으로 남고 진행 단계 날짜가
  전부 무시되던 문제 수정 — 새 심의방법 "전자결재(본부장)"을 추가하고
  "전자결재" 원문을 여기로 매핑. 심의방법 드롭다운에도 추가됨.

v0.24 (날짜 필드 클릭 범위 수정)
-------------------------------------
- 목록·상세 보기의 진행 단계 날짜를 고치려 할 때, 라벨의 오른쪽 끝(브라우저 기본
  달력 아이콘 자리)을 정확히 클릭해야만 달력이 열리고 가운데·왼쪽을 클릭하면
  반응이 없던 문제 수정. 이제 라벨 어디를 클릭해도 달력이 뜸.

v0.23 (레거시 업로드 — CFT 부서 "해당없음" 구분)
-------------------------------------
- 옛 엑셀에서 CFT 8개 부서 중 검토가 필요 없어 "-"로 적어둔 부서가 "미입력"으로
  읽혀서, 실제로는 결재완료까지 끝난 안건이 "CFT검토중"에 계속 머물러 있던 문제
  수정. 이제 "-"는 "해당없음"으로 구분해서 읽고 상세보기에도 그렇게 표시됨.

v0.22 (레거시 업로드 — 국책사업 행 인식 수정)
-------------------------------------
- 구 엑셀(관리대장) 업로드 시 계약번호가 공란이고 내부관리번호만 있는 행(국책사업
  건)이 전부 일반 "사업"으로 생성되던 문제 수정. 이제 "내부관리번호" 열이 있으면
  계약번호가 빈 행은 국책사업으로 인식해 표/칸반에 국책사업 배지가 뜸.

v0.21 (CFT 8부서별 검토, 레거시/국책사업 데이터 업로드 추가)
-------------------------------------
- 안건 상세에서 유관부서(CFT) 검토를 AI/S·W 시험/개발 구매/개발 품질/원가 분석/M&S/
  체계공학/사업관리 8개 부서별로 날짜를 따로 입력하고, 전부 완료돼야 다음 단계로
  넘어가도록 변경 (기존엔 CFT 검토를 한 덩어리로만 관리)
- "레거시 데이터 업로드" 기능 추가 — 과거에 쓰던 구 엑셀(관리대장) 파일을 올리면
  계약번호 기준으로 기존 안건과 자동 병합하거나 새 안건으로 생성함
- "포털 동기화" 버튼을 "포털 데이터 업로드"로 바꾸고 사업/국책사업 두 양식을 선택해
  올릴 수 있게 함. 국책사업 양식은 BM/BM부서/PM/계약금액 등 전용 열 위치로 읽고
  기본 심의방법을 "서면보고(전자결재)"로 자동 지정함
- 안건을 완전히 삭제하면 되돌릴 수 없다는 점을 명확히 안내하는 확인창 추가
- 예시 데이터에 국책사업 4건 포함, 총 29건으로 재구성

v0.20 (사용자 요청: 선택 삭제를 완전 삭제로 변경, 선택 툴바 스크롤 고정)
-------------------------------------
- 표 보기에서 안건을 선택해 "선택 제외처리"하던 기능을 "선택 삭제"(완전 삭제, 복원 불가)로
  바꿈. 안건 상세의 휴지통 버튼도 동일하게 완전 삭제로 동작함.
  (주의: 포털 동기화가 사라진 항목을 자동으로 "제외" 처리하는 기존 기능은 그대로 유지되며,
  이 항목은 여전히 복원 가능함 — 이번 변경은 사람이 직접 삭제 버튼을 누르는 경우에만 해당)
- 표 보기에서 여러 건을 선택하면 나타나는 보라색 선택 툴바(PM 재배정/심의방법 변경/사업부문
  지정/선택 삭제)가 스크롤해도 화면 상단에 계속 보이도록 고정함.

v0.19 (버그 수정: "확정" 버튼이 심의방법 미지정 상태에서 추천 분류를 적용하지 않던 문제)
-------------------------------------
- v0.18에서 신규 안건 심의방법 기본값을 "미실시"→"미지정"으로 바꿨는데, 안건 상세의
  "확정" 버튼 로직이 여전히 "미실시"를 기준으로 판단해 신규 안건에서 확정을 눌러도
  심의방법이 추천값(서면보고/대면보고 등)으로 바뀌지 않고 "미지정"에 그대로 머무는
  문제가 있었음. 기준값을 "미지정"으로 수정.
- 영향 받은 기존 데이터가 있다면 안건 상세의 "재적용" 버튼으로 복구 가능.

v0.18 (사용자 피드백 4건 반영: 일괄 제외처리·기본값·금액 콤마·BM/PM 부서)
-------------------------------------
- 표 보기에서 체크박스로 여러 건을 고른 뒤 **선택 제외처리** 버튼으로 한 번에 제외 처리할 수
  있게 됨 (완전 삭제 아님, 기존 단건 제외와 동일하게 언제든 복원 가능)
- 새 안건의 심의방법 기본값을 "미실시"에서 "미지정"으로 변경 — "미실시"는 이제 "검토해보니
  안 해도 됨"이라는 명시적 판단을 뜻하고, 아직 아무도 안 정한 상태는 "미지정"으로 구분됨.
  진행 단계(칸반·필터·완료기한 지연/CFT 지연/정체 안건 판정)에도 "미지정" 전용 상태를 추가해서
  "미실시"/"대상아님"과 똑같이 지연·정체 판정에서 제외되도록 함
- 계약금액에 천단위 콤마 표시 추가 (상세 팝업·목록·상세 보기·표 보기 모두) — 수정할 때는
  그대로 숫자만 입력하면 됨
- BM 이름·BM 부서·PM 부서 필드를 안건 추가 모달·상세 팝업·목록·상세 보기·표 보기 컬럼·
  엑셀 내보내기·변경 이력에 전부 추가. 데이터 모델에는 이미 있었지만 화면 어디에도 노출이
  안 되고 있었음 — 특히 "BM 부서"는 포털의 "담당부서" 컬럼을 그대로 쓰는 거라 기존 "부서"
  라벨이 실제로는 BM 쪽 정보였음을 명확히 함. "PM 부서"는 새로 추가한 팀 입력 필드.

v0.17 (대면보고를 "대면보고(부문장)"·"대면보고(연구개발본부장)" 둘로 분리)
-------------------------------------
- 기존엔 심의방법이 "대면보고" 하나였는데, 실제로는 결재권자가 둘로 갈림 — 손충금 사업이면
  부문장, 그 외(무기체계 300억↑/핵심기술 150억↑ 금액 기준 충족)는 연구개발본부장. 이제
  심의방법 선택지 자체가 "대면보고(부문장)"/"대면보고(연구개발본부장)" 둘로 나뉨
  (표 보기·상세 팝업·일괄 변경 드롭다운 전부 동일하게 반영)
- 1차 분류 추천값은 항상 "대면보고(연구개발본부장)"을 기본으로 계산하고, 손충금 사업 체크 후
  확정/재적용할 때만 "대면보고(부문장)"으로 강제 적용됨 — 추천값 자체가 손충금 여부로
  바뀌지는 않고, 최종 확정 시점에만 갈림
- 진행 단계 계산(미실시/대상아님 판정, 칸반·필터의 상태 구분)도 두 변형 모두 똑같이
  "대면보고 계열"로 인식하도록 수정 — 둘 다 PM요청→결재완료 흐름을 그대로 탐
  (실제 레코드로 손충금 체크/해제→확정/재적용 전 과정과 칸반 보드 단계 분류까지 라이브로 재검증)
- 데모 데이터(25건)의 기존 "대면보고" 값도 전부 실제 결재권자(부문장/본부장/대표이사) 기준에
  맞춰 두 변형 중 하나로 재분류

v0.16 ("대상아님" 안건에 빈 진행 단계 스테퍼가 통째로 뜨던 버그 수정)
-------------------------------------
- 심의방법이 "대상아님"인 안건을 열면 "심의 미실시"처럼 안내 문구만 떠야 하는데, 실제로는
  PM요청부터 결재완료까지 6개 날짜 입력칸이 전부 빈 채로 그려지고 있었음 — 심의 대상이 아닌
  안건에 날짜를 입력하라고 유도하는 셀이라 혼란스러움. "목록·상세 보기"와 상세 팝업 양쪽에서
  공통으로 쓰는 진행 단계 컴포넌트(VerticalStepper)라 두 화면 다 같이 고쳐짐. 실제 레코드로
  재현(6개 빈 날짜칸 확인) 후 수정(안내 문구로 교체) 확인.

v0.15 ("대상아님" 안건이 "정체 안건"·"CFT 지연"에도 잘못 잡히던 버그 수정)
-------------------------------------
- 현황 요약의 "정체 안건 경고" 목록도 v0.14와 같은 원인으로 "대상아님" 안건을 잘못 포함하고
  있었음 — "미실시"만 제외하고 "대상아님"은 빠져 있어서, 진행 이력이 없는 "대상아님" 안건이
  엉뚱하게 1위로 뜨는 문제를 재현 후 수정
- CFT 지연 판정(isCftOverdue)은 아예 심의방법/단계를 전혀 안 보고 cftRequest 날짜 유무로만
  판단하고 있었음 — 한 번 CFT 검토가 시작된 뒤에 심의방법을 "미실시"/"대상아님"으로 바꿔도
  예전 cftRequest 날짜가 남아있어서 계속 CFT 지연으로 잡히던 문제를 재현(실제 레코드로 재현,
  배너가 사라지는 것까지 확인) 후 수정 — 이제 "미실시"/"대상아님" 단계면 cftRequest 날짜와
  무관하게 CFT 지연 대상에서 제외됨

v0.14 ("대상아님"·"미실시" 안건이 완료기한이 지나면 잘못 "지연"으로 잡히던 버그 수정)
-------------------------------------
- 심의방법이 "대상아님"인 안건은 원래 완료기한 관리 대상이 아닌데, 완료기한이 지나면
  "완료기한이 지난 안건" 배너와 "지연만" 필터에 잘못 포함되던 문제 수정 (실제 레코드를
  "대상아님" + 과거 완료기한으로 만들어 재현 후 수정 확인 — 6건→7건으로 잘못 늘었다가 수정 후 6건으로 복구)
- 칸반 보드 세로형의 "완료기한" 열에서도 같은 이유로 "미실시"/"대상아님" 안건에 빨간
  "N일 초과" 경고가 잘못 뜨던 것을 같이 수정 (이 화면은 "결재완료"만 제외하고 있어서 범위가 더 넓었음)

v0.13 (일정 > 타임라인에서 신규 안건을 열어도 "확인함" 처리가 안 되던 버그 수정)
-------------------------------------
- "목록·상세 보기"는 왼쪽 목록에서 신규(✨) 안건을 클릭해 선택하면(팝업 없이도) 자동으로
  "확인함" 처리되는데, "일정 > 타임라인"의 왼쪽 목록은 똑같은 방식(클릭 → 선택, 팝업 없음)인데도
  "확인함" 처리가 전혀 안 되고 있었음 — 같은 안건을 몇 번을 클릭해도 ✨ 표시가 영원히 안 없어짐
- 목록·상세 보기와 같은 처리 로직을 타임라인에도 추가해서, 두 화면에서 "신규" 표시가 똑같이
  동작하도록 수정 (실제 레코드로 재현 후 수정 확인)

v0.12 (필터 바의 "N건" 칩 배지가 부문 탭과 무관하게 고정되던 버그 수정)
-------------------------------------
- "신규 N건", "CFT 지연 N건", "심의 대상 확정 필요 N건", "PM 미배정 N건" 칩이 지금 선택된
  부문 탭과 무관하게 항상 전체 데이터 기준 숫자를 보여줘서, 칩을 눌렀을 때 그 숫자보다 적게
  (또는 0건) 나오는 경우가 실제 더미데이터로도 재현됨 (예: "심의 대상 확정 필요 4건"을 눌러도
  "미래전장사업부문" 탭에서는 0건만 표시) — v0.10의 부서/PM 드롭다운과 같은 원인의 버그
- 이제 이 칩들의 배지 숫자도 부문 탭으로 좁힌 집합 기준으로 계산되어서, 현재 탭에 해당 건이
  없으면 칩 자체가 안 보이고, 숫자가 보이면 누른 결과와 항상 일치함
  ("미지정" 탭 배지(부문 미지정 건수)는 이 부문 탭들의 판단 기준 자체라 예외적으로 전체 기준 유지)

v0.11 ("전체 확인하기" 배너가 부문 탭을 안 바꿔서 건수가 안 맞던 버그 수정)
-------------------------------------
- "완료기한이 지난 안건 N건", "CFT 검토 요청 후 N일 지난 안건 N건" 배너의 "전체 확인하기"를
  눌러도 그 당시 선택되어 있던 부문 탭(미래전장사업부문/그 외 부문/미지정)이 그대로 유지돼서,
  배너가 말한 건수보다 적게 보이는 경우가 있던 문제 수정 — 이제 "전체 확인하기"를 누르면
  부문 탭도 함께 "전체"로 바뀌어서 배너에 적힌 건수와 실제 표시되는 건수가 항상 일치함
  (현재 더미데이터에서는 우연히 드러나지 않았지만, 지연/CFT 지연 안건이 "미지정"이나 "그 외
  부문"에 있을 때 재현되는 구조적 버그였음 — 실제로 레코드를 하나 그 상태로 만들어서 재현 후 수정 확인)

v0.10 (부서·PM 필터 선택지가 부문 탭과 무관하게 고정되던 버그 수정)
-------------------------------------
- 부문 탭(미래전장사업부문/그 외 부문/미지정/전체)을 바꿔도 그 아래 "전체 부서"·"전체 PM"
  드롭다운의 선택지 목록이 항상 전체 데이터 기준으로 고정되어 있던 문제 수정 — 이제 부서/PM
  드롭다운은 지금 선택된 부문 탭에 속한 안건들만 기준으로 선택지가 좁혀진다
  (예: "미지정" 탭에서는 실제로 미지정 안건이 있는 부서만 뜨고, PM은 전부 미배정이라 "전체 PM"만 남음)

v0.09 (손충금·사업형태·적용사업·클릭영역 버그 수정)
-------------------------------------
- 손충금 체크를 바꿨는데 이미 "확정됨" 상태라 반영할 방법이 없던 문제 수정 — 체크 상태와
  현재 심의방법이 어긋나면 "재적용" 버튼이 다시 나타나서 명시적으로 반영할 수 있음
- "안건 추가" 모달과 안건 상세 팝업에 "사업형태"(무기체계/핵심기술/그 외) 선택란 추가 — 그동안
  수동으로 등록한 안건은 사업형태를 지정할 방법이 없어서 1차 분류 기능이 전혀 동작하지 않았음
- "안건 추가" 모달에 계약금액 입력란도 추가 (분류 판정에 금액이 필요해서 같이 추가)
- 사업형태나 계약금액을 수정하면 1차 분류 추천값이 그 즉시 다시 계산되도록 수정 (이전에는
  포털 동기화로 들어온 데이터만 재계산되고, 사람이 직접 고친 경우엔 추천값이 갱신되지 않았음)
- "적용사업" 예시 데이터가 부서명("배터리사업부" 등)으로 잘못 채워져 있던 것을 실제 사업요약명
  스타일(청상어, 천궁, TACM 등)으로 교체
- 값이 비어서 "-"만 보일 때 그 글자 위만 클릭해야 수정 모드로 들어가던 문제 수정 — 이제 필드
  박스 전체 어디를 클릭해도 수정 가능
