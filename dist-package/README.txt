개발심의회 대시보드 - 테스트 실행 안내
=====================================
버전: v0.27

■ 실행 방법 (설치 필요 없음, 3단계)

1. 이 폴더의 "run.txt" 파일 이름을 "run.bat"으로 바꾸세요.
   (파일 우클릭 → 이름 바꾸기 → 확장자를 .txt에서 .bat으로 변경)

2. "run.bat"을 더블클릭하세요.

3. 검은 화면(cmd 창)이 뜨고 잠시 후 브라우저가 자동으로 열리며 앱이 나타납니다.
   그 창에서 바로 웹앱을 사용하시면 됩니다.

   ※ 그 검은 창은 서버가 켜져 있다는 뜻입니다. 테스트하는 동안 닫지 말고 그대로 두세요.
   ※ 테스트가 끝나면 그 창을 그냥 닫으면 됩니다. (별도 종료 절차 없음)


■ 실행 중 화면이 하나 뜰 수 있습니다

"Windows에서 PC를 보호했습니다"라는 파란 화면이 뜨면:
  → "추가 정보" 클릭 → 아래에 나오는 "실행" 버튼 클릭

  (이 프로그램에 서명이 없어서 Windows가 한번 확인하는 절차이며, 실제 위험한 프로그램이 아닙니다.
   함께 전달받은 프로젝트 담당자가 직접 만든 테스트용 프로그램입니다.)


■ 예시 데이터

이 테스트 패키지는 처음 열었을 때부터 예시 안건 29건이 이미 들어있습니다(미실시부터
결재완료까지 모든 진행 단계, 지연된 안건, 국책사업 4건 포함) — 빈 화면이 아니라 실제
사용 모습 그대로 바로 둘러볼 수 있습니다.

헤더의 "포털 데이터 업로드" 기능까지 테스트해보고 싶으면 sample-data 폴더 안의 예시
엑셀 파일을 올려보세요.
- 사업: portal_data_v1.xlsx / portal_data_v2.xlsx
- 국책사업: gov_project_sample_template.xlsx (업로드 버튼에서 "국책사업" 선택)
기존 데이터는 그대로 두고 새 안건 몇 건이 "신규"로 추가되는 걸 확인할 수 있습니다.

구 엑셀(과거 관리대장) 데이터를 옮겨오는 "레거시 데이터 업로드" 기능은
original_management_data_template.xlsx 또는 legacy_dummy_test.xlsx로 테스트할 수
있습니다 — 계약번호가 같으면 기존 안건에 병합되고, 없으면 새 안건으로 생성됩니다.


■ 사용설명서

이 폴더의 "manual" 폴더에 사용설명서가 들어있습니다. 인터넷 연결 없이 보려면
"manual\manual_offline.html" 파일을 더블클릭해서 브라우저로 열면 됩니다(이미지까지
파일 하나에 전부 들어있어 폐쇄망에서도 바로 열립니다). 텍스트로만 보려면
"manual\manual.md"를 열어도 됩니다.


■ 문제가 생기면

- 브라우저가 자동으로 안 열리면: 아무 브라우저나 열어서 주소창에 http://localhost:4000 입력
- 검은 창에 에러 메시지가 보이면: 그 내용을 그대로 캡처해서 보내주세요.


■ 참고

- 이 테스트 패키지에는 사내 AI(LLM) 연결용 API 키가 비어 있습니다. AI 어시스턴트 화면 외의
  모든 기능(표 보기, 칸반 보드, 포털 데이터 업로드, 레거시 데이터 업로드, 일정 등)은
  정상적으로 테스트 가능합니다.
